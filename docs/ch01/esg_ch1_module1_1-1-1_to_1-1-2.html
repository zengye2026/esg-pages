Module Map · Hidden Lines

两根隐藏线：从“资本选择”到“宏观压力”

先看结构，再记细节。第 1 章开头最容易错在把 SRI、impact、green、engagement 等概念当成孤立名词；实际上它们都在回答同一组问题。

1.1.1 · 投资方法
Responsible investment == 资本如何被筛选、配置、并影响发行人
逻辑总式
ESG / Responsible Investment == 投什么 + 为什么投 + 怎么影响
投什么：portfolio construction；为什么投：财务回报、影响、价值观；怎么影响：engagement 是唯一“不靠持仓构建”的例外。
  • 先判断：是否只追求财务回报？是否愿意接受低于市场回报换取高影响？
  • 再判断：用 negative screening、positive screening、theme、impact measurement，还是 active ownership？
  • 最后记住例外：engagement 不是“选什么证券”，而是“如何影响发行人”。
→
1.1.2 · 宏观争论
ESG incorporation == 六类压力共同把 ESG 推进投资决策
逻辑总式
纳入 ESG == 风险变了 + 责任变了 + 经济底盘变了 + 价值目标变了 + 客户变了 + 规则变了
这六项分别对应 risk、fiduciary duty、economic、impact & ethics、client demand、regulation。
  • 不是“做好事”这么简单，而是风险、收益、系统稳定、客户偏好和法规共同作用。
  • 金融系统稳定的核心线：长期 ESG 风险可能变成系统性风险，投资者需要更长视角。
  • Universal owners 是经济视角的关键角色：持有全市场切片，所以依赖整体经济健康。
定义 ESG
显式纳入 ESG，目标是长期风险调整回报。
分类方法
SRI、best-in-class、sustainable、thematic、green、social、impact、ethical / faith-based、engagement。
识别陷阱
Engagement 是例外；best-in-class 是 positive screening；ethical / faith-based 多用 negative screening。
六视角纳入
风险、责任、经济、影响伦理、客户、监管共同解释 ESG incorporation。

Logic Equation Cards

逻辑等式卡片

每张卡按 skill 的“题目 → 答案 → 隐藏线 → 逻辑等式 → 记忆钩子”来做。核心是理解，不是硬背。

定义

1. ESG investing 的本体

题目拆解：ESG investing = ESG + investing。ESG 是“看什么因素”，investing 是“为了什么投资目标”。所以答案自然由“显式纳入因素”与“长期风险调整回报”组成。
ESG investing==Explicitly incorporate ESG factors + investment decisions + long-term risk-adjusted return
区别==ESG investing 更关注 ESG 如何影响资产/证券的长期回报；其他 responsible approaches 还可能考虑非财务价值创造和 stakeholder values。
记忆钩子：ESG investing 不是“我喜欢环保公司”，而是“把 ESG 当作长期风险调整回报的输入”。
E/S/G 范围

2. 为什么 E/S/G 没有统一边界？

隐藏线：E/S/G 是用来服务不同 framework 与 stakeholder 的分类工具，不是自然界先天画好的三条线。因此会 overlap。
E==Natural world + renewable / non-renewable resources：water、minerals、ecosystems、biodiversity
S==Lives of humans + human capital + non-human animals + local communities + clients
G==Jurisdictions / industry practices + broader stakeholder interests
边界==No universal standard + overlap；动物福利可同时属于 E 和 S。
短期主义

3. Short-termism 为什么伤害 ESG？

题目拆解：short-termism = short + term + ism。它的问题不是“短”本身，而是把“短期价格/近利结果”凌驾于长期价值之上。
Short-termism==短线交易价格波动 + 互动时逼公司最大化 near-term financial results
后果==R&D / patient capital 被抑制 → bubbles / financial instability / economic underperformance → ESG 等长期因素被忽略
SRD==EU regulatory initiative to counter short-termism：active ownership + long-term focus
考点：问 SRD 的目的，答案是 counter short-termism，不是 proxy 或 minority shareholders。
总伞

4. Responsible investment 与 portfolio construction

隐藏线：绝大多数 responsible investment 都是在问“基金持有什么证券”；只有 engagement 在问“投资者如何影响发行人”。
Responsible investment==ESG factors into investment decisions + active ownership
Minimum==Mitigate risky ESG practices to protect value
考试例外==All forms except engagement are related to portfolio construction
记忆钩子：“投什么”是一类；“怎么影响已投对象”是 engagement。
Engagement

5. Shareholder engagement 的三件事

题目拆解：engagement = investor seeks to influence a corporation’s decisions on ESG matters。自然会拆成“影响方式”和“影响有效性”。
方式==Dialogue with corporate officers + votes at shareholder assembly
有效性==Scale of ownership + quality of dialogue/method + divestment as possible sanction
定位==Complementary to responsible investment approaches；鼓励公司按 stakeholder best interest 行动。
CSR

6. CSR 与 ESG investing 的关系

隐藏线：CSR 是公司怎么经营；ESG investing 是投资者如何把公司经营质量纳入选择。
CSR==Company commitment to conducting business ethically
Corporate sustainability==Long-term stakeholder value + ethical / social / environmental / cultural / economic dimensions
ESG investing==把 license to operate、efficiency、regulation、fines、employee satisfaction、innovation 等公司收益放入 asset / security selection 与 portfolio construction
双向关系

7. ESG 与 investment 的动态关系

这一点是全章的“总开关”：不是只有公司影响世界，也不是只有世界影响公司，而是两边互相影响。

ESG → 投资==E/S/G issues may impact risk、volatility、long-term return of securities and markets
投资 → 世界==Investments can have positive or negative impact on society and environment
后续承接：这张卡会接到 Module 2 的 financial / double / dynamic materiality。
陷阱

8. 常见混淆：ESG、SRI、impact、CSR

ESG investing≠纯价值观投资；它以 long-term risk-adjusted return 为核心。
Impact investing≠philanthropy；它要求 financial return，同时要求 positive measurable impact。
CSR≠ESG investing；CSR 是公司层面，ESG investing 是投资者层面。
Best-in-class≠negative screening；它是 positive screening。
Responsible Investment Spectrum

投资方法谱系：从捐赠到传统财务投资

这一页专门解决名词太多的问题：先用资本谱系定位，再用“筛选 / 主题 / 影响 / 价值观 / 互动”分类。

最左端

Philanthropy

捐赠 / grants 解决社会挑战；没有 ESG metrics；只期待社会回报，不期待金融市场回报。

No financial return expectation
影响导向

Impact Investing

有意图地产生可衡量的环境 / 社会结果，同时获得金融回报；难点是机会集减少与 impact measurement。

Impact + financial return
长期价值

Sustainable & Responsible Investing

ESG investing：screening / thematic / integration / stewardship；为风险缓释与机会识别增强长期价值。

Long-term ESG risk-adjusted return
最右端

Traditional Financial Investing

Conventional investing：只在风险约束下最大化财务回报；无明确社会 / 环境关注；挑战是可能错过 ESG risk factors。

Financial return only
Approach核心定义记忆等式考点陷阱
SRI用社会和环境标准评价公司；按 criteria 给公司评分，通常结合 sector-specific weightings；设 hurdle 得到 SRI-qualified companies。SRI == score + hurdle + first screen可与 best-in-class / thematic / high-conviction / quant 组合。
Best-in-class在每个 sector / industry 内用 ESG criteria 设排名门槛，只选超过门槛的公司。Best-in-class == positive screening within each sector不等于所有 best-in-class funds 都是 responsible investments；常用于维持 index 特征。
Sustainable investment选择对 sustainable economy 有贡献的资产，最小化自然和社会资源耗竭。Sustainable == contribute to sustainable economy + minimize resource depletion既可包括 BIC / ESG integration，也可筛掉 coal、Arctic oil 等不可持续活动。
Thematic investment基于环境或社会挑战产生的投资主题。Thematic == environmental/social needs → investment theme低碳能源、水、医疗、营养等；不是所有 thematic fund 都是 responsible 或 best-in-class。
Green investment投向缓解气候变化、生物多样性丧失、资源低效和其他环境挑战的资产。Green == environmental challenge solverGreen bonds 是专门为气候 / 环境项目筹资的 fixed-income instrument。
Social investment投向解决社会挑战的资产，尤其 BOP。Social == social challenges + BOP + basic accessBOP = 最贫困的经济金字塔底部；microfinance / microinsurance 是典型例子。
Impact investment特定意图地产生积极、可衡量的社会或环境影响，同时获得金融回报。Impact == specific intent + measurable impact + financial return区别于 philanthropy；measurement and tracking 是核心；回报可低于市场、市场竞争或超越市场。
Ethical / values-driven / faith-based按原则投资，常用 negative screening 排除道德上不可接受的产品或服务。Ethical == principles → negative screening典型排除：tobacco、alcohol、pornography、weapons、重大违反协议；Shari’a 还涉及 interest / gambling / pork。
Shareholder engagement通过 dialogue 或 voting 影响公司 ESG 决策。Engagement == active ownership → influence issuer behavior唯一不是 portfolio construction 的 approach；有效性看 ownership scale、dialogue quality、divestment threat。

Macro-Level Debate

ESG 纳入投资决策的六个宏观视角

这部分最适合用“六扇门”场景记忆：投资者不是主动浪漫地选择 ESG，而是从六个方向同时被推向 ESG incorporation。

六视角总式
ESG incorporation == Risk + Fiduciary Duty + Economics + Impact & Ethics + Client Demand + Regulation
中文压缩：怕风险 + 守责任 + 保经济 + 做影响 / 避免伤害 + 顺客户 + 遵监管。
Risk

1. 风险视角：风险版图已经变了

Risk perspective==Global megatrends → extreme weather / climate failure ↑ → classic economic risks no longer dominate top risk discussion
Carney==Tragedy of the horizon：气候风险发生在传统政策 / 金融稳定视野之外，等它成为金融稳定定义性问题时可能已太晚。
证券选择==问公司 today emissions + net-zero transition plan；在快速变化风险图景中识别 winners / losers。
案例线：水资源 / 气候风险 → PG&E wildfire liabilities；CBA 水危机影响 EBITDA；Peru 水冲突导致 mining projects suspension。
Fiduciary Duty

2. 受托责任视角：从“不许看 ESG”到“必须看 ESG”

旧误解==ESG 不具财务重要性 → fiduciary duty 成为不纳入 ESG 的理由
现代解释==Failing to consider long-term value drivers including ESG == failure of fiduciary duty
1
Incorporate financially material ESG into decision making, consistent with obligation time frame.
2
Understand and incorporate sustainability preferences of beneficiaries / clients, even if not financially material.
3
Be active owners and encourage high ESG standards.
4
Support stability and resilience of the financial system.
5
Disclose clearly investment approach and how preferences are incorporated.
Economics

3. 经济视角：坏趋势会拖垮整体经济底盘

经济风险==Water / energy / land scarce and expensive + health / income inequalities → instability → weakened economies
系统风险==FSB identified climate change as potential systemic risk；other environmental megatrends may also be systemic。
Universal owners==Large diversified institutions hold a slice of the overall market → returns depend on overall economy health。
外部性逻辑==High negative externalities in one company can damage other portfolio companies and market return → investors should price externalities。
Impact & Ethics

4. 影响与伦理视角：钱应该服务社会，至少不要伤害社会

Positive impact==Investment / stewardship as means to tackle social and environmental problems → impact investing
Avoid harm==Negative screening of controversial sectors：arms、gambling、alcohol、tobacco、pornography；也可排除 fossil fuels 或 governance breaches。
记忆钩子：这一视角分两半：往好处投；从坏处撤。
Client Demand

5. 客户需求视角：资金主人要看清钱去了哪里

Demand==Clients call for transparency about how and where money is invested
原因==Awareness ESG influences company value / returns / reputation + focus on environmental / social impacts of investees
Asset owners==Instrumental because they decide how assets are managed；Net-Zero Asset Owner Alliance committed portfolios to net-zero GHG by 2050。
Regulation

6. 监管视角：不管你信不信，都越来越要做

趋势==Responsible investment regulation increased since mid-1990s, surged after 2008 financial crisis
监管动因==Financial sector can help address climate change, modern slavery, tax avoidance
PRI 数据==48 of 50 largest economies have relevant policies；730+ hard / soft law policy revisions
Hard vs Soft==Hard law = binding legal instruments；Soft law = quasi-legal, weaker/non-binding, but may become hard law over time。
Self Test · Module 1

自测题

先不要看答案。尤其注意 exception、least likely、positive vs negative screening、company level vs investor level。

1 · 定义
ESG investing 的完整定义应该包含哪三个要素？
显式纳入 ESG factors；发生在 investment decisions 中；目标是 long-term risk-adjusted return。
2 · ESG vs Responsible
ESG investing 与其他 responsible investment approaches 的重点区别是什么？
ESG investing 更关注 ESG issues 如何影响资产和证券的长期回报；其他 responsible approaches 还可能考虑非财务价值创造和 stakeholder values。
3 · E/S/G 范围
为什么 E/S/G 因素没有统一边界？举一个 overlap 例子。
因为 E/S/G 的划分取决于具体框架、定义者和 stakeholders；不是全球统一标准。例子：animals / animal well-being 可同时被视为 environmental 和 social factors。
4 · Exhibit 2
E、S、G 各自的定义关键词是什么？
E = natural world / resources；S = lives of humans + human capital / animals / communities / clients；G = jurisdictions / industry practices / broader stakeholder interests。
5 · Short-termism
Short-termism 在本节中最相关的两种表现是什么？
① 根据短期价格波动进行交易，而不是长期价值；② 与被投公司互动时，优先最大化 near-term financial results，而不是 long-term value creation。
6 · SRD
EU Shareholder Rights Directive 的考点目的是什么？
Counter short-termism。它要求投资者成为 active owners，并以更长期的焦点行动。
7 · Portfolio construction
哪一种 responsible investment approach 不属于 portfolio construction？
Shareholder engagement。其他形式最终都和基金持有什么证券有关；engagement 关注投资者是否以及如何影响 issuer behavior。
8 · Spectrum of capital
资本谱系从左到右是哪四类？越往左意味着什么？
Philanthropy → Impact Investing → Sustainable & Responsible Investing → Traditional Financial Investing。越往左越重视 positive environmental/social outcomes，甚至可能接受低于市场回报。
9 · SRI
SRI 的基本操作链条是什么？
用 social / environmental criteria 评分 → 通常配 sector-specific weightings → 设 qualification hurdle → 得到 SRI-qualified companies 的 first screen。
10 · Best-in-class
Best-in-class 又叫什么？为什么它适合维持 index characteristics？
又叫 positive screening。它在每个 sector / industry 内选 ESG 排名超过门槛的公司，因此可以保持行业和地区分散度，接近 benchmark profile。
11 · Sustainable
Sustainable investment 的核心是什么？它也可以筛掉哪些活动？
核心是选择有助于 sustainable economy 的资产，最小化自然和社会资源耗竭。也可以筛掉不符合长期环境和社会可持续性的活动，如煤炭开采/燃烧或北极石油勘探。
12 · Thematic
Thematic investment 的常见环境主题和社会主题是什么？有什么陷阱？
环境主题：低碳能源、水资源获取和高效利用。社会主题：医疗和营养可及性等。陷阱：不是所有 thematic funds 都是 responsible investments 或 best-in-class，取决于主题和被投公司的 ESG 特征。
13 · Green
Green investment 投向什么？Green bonds 是什么？
投向缓解 climate change、biodiversity loss、resource inefficiency 和其他 environmental challenges 的资产。Green bonds 是专门为气候和环境项目筹资的固定收益工具。
14 · Social / BOP
Social investment 与 BOP 的关系是什么？典型例子有哪些？
Social investment 投向解决社会挑战的资产，可服务 BOP（最贫困的经济金字塔底部，超过 40 亿人）。例子：microfinance、microinsurance、基础电信、营养和医疗、清洁能源、social impact bonds。
15 · Impact
Impact investing 与 philanthropy 的关键区别是什么？
Impact investing 要有 specific intent，产生 positive measurable social/environmental impact，同时获得 financial return；measurement and tracking 是投资主张的核心。Philanthropy 不要求金融市场回报。
16 · Ethical / Faith-based
Ethical / faith-based investment 通常用什么筛选？典型排除项有哪些？
通常用 negative screening。典型排除：tobacco、alcohol、pornography、weapons、重大违反国际协议。Shari’a 还涉及 alcohol / pornography / gambling / interest / pork 等限制。
17 · Engagement
Shareholder engagement 的方式和有效性条件是什么？
方式：dialogue with corporate officers 或 shareholder assembly voting。有效性：ownership scale、dialogue quality/method、公司是否知道 divestment 是可能制裁。
18 · CSR
CSR 和 ESG investing 的关系是什么？CSR 管理好会带来哪些公司收益？
CSR 是公司承诺以伦理方式经营；ESG investing 是投资者把这些因素纳入证券选择和组合构建。收益包括 license to operate、效率提升、满足监管、减少罚款概率、提升员工满意度和生产力、推动创新和新产品线。
19 · 六视角
宏观层面为什么要把 ESG 纳入投资决策？六个视角是什么？
Risk、Fiduciary duty、Economics、Impact and ethics、Client demand、Regulation。中文压缩：怕风险、守责任、保经济、做影响/避伤害、顺客户、遵监管。
20 · Risk perspective
Risk perspective 下，为什么气候风险与金融稳定有关？
气候风险可能超出传统货币政策和信用周期视野，等它成为金融稳定的定义性问题时可能已经太晚。投资者因此要看公司当前排放和 net-zero transition plan，并识别风险变化中的 winners / losers。
21 · Fiduciary duty
现代 fiduciary duty 为什么不再是 ESG 的障碍？它要求投资者做哪五件事？
因为不考虑长期价值驱动因素（包括 ESG）反而可能是 fiduciary duty failure。五件事：纳入 financially material ESG；理解并纳入 beneficiary/client sustainability preferences；做 active owners；支持 financial system stability and resilience；清晰披露投资方法。
22 · Economic perspective
Universal owners 为什么特别关心 ESG 和外部性？
Universal owners 是大型高度分散机构，等于持有整个市场的一片切片，回报依赖整体经济健康。高负外部性公司会伤害其他组合公司和总市场回报，所以它们有动力降低 sustainability challenges 带来的经济风险。
23 · Impact & Ethics
Impact and ethics perspective 的两条路径是什么？
① 投向 positive impact：用资本和 stewardship 解决社会/环境问题；② 避免 negative impact：用 negative screening 排除 arms、gambling、alcohol、tobacco、pornography、fossil fuels 或 governance breaches 等。
24 · Client demand
Client demand 为什么推动 responsible investment？
客户越来越要求透明了解钱如何、投到哪里；他们意识到 ESG 影响 company value、returns 和 reputation，也更关注被投公司的环境和社会影响。Asset owners 决定资产如何被管理，因此很关键。
25 · Regulation
Regulatory perspective 的核心数据和 hard / soft law 区别是什么？
PRI 发现 50 个最大经济体中 48 个有帮助投资者考虑 sustainability risks / opportunities / outcomes 的政策；有 730+ hard/soft law revisions。Hard law 是有约束力的法律工具；soft law 是准法律、约束力较弱或非约束，但可能逐渐变成 hard law。
Final Review

压缩背诵版

考前 8 分钟快速扫这一页。先背等式，再背例外。

Master Equation 1

1.1.1：Responsible investment == 投什么 + 为什么投 + 怎么影响

ESG investing = explicitly incorporate ESG factors in investment decisions with long-term risk-adjusted return in mind。Responsible investment = ESG into decisions + active ownership。所有 responsible investment 除 engagement 外都与 portfolio construction 有关。

ESG 范围

E = natural world；S = lives of humans；G = jurisdiction / industry practice / stakeholders。无统一标准，会 overlap。

Short-termism

短线价格交易 + 近利互动。后果：R&D / patient capital 下降、bubbles、financial instability、忽视 ESG。SRD = counter short-termism。

Capital Spectrum

Philanthropy → Impact → Sustainable & Responsible → Traditional。越左越重视 impact，越右越只追求 financial return。

SRI / BIC

SRI = social/environmental criteria + score + hurdle。Best-in-class = positive screening within each sector。

Sustainable / Thematic

Sustainable = sustainable economy + resource depletion minimized；Thematic = environmental/social challenge themes，不一定 responsible。

Green / Social

Green = environmental challenge solver；Social = social challenges + BOP；microfinance 是 social，不是 green。

Impact

Specific intent + positive measurable impact + financial return。Measurement and tracking 是核心。

Ethical / Faith-based

Principles → negative screening。排除 tobacco、alcohol、pornography、weapons、重大违反协议；Shari’a 包含 interest / gambling / pork 等。

Engagement

Active ownership → dialogue / voting。有效性 = ownership scale + dialogue quality + divestment sanction。

Master Equation 2

1.1.2：ESG incorporation == 风险 + 责任 + 经济 + 影响伦理 + 客户 + 监管

Risk 看宏观风险变化；Fiduciary duty 看长期价值驱动因素；Economics 看系统稳定与 universal owners；Impact & ethics 看正面影响或避免伤害；Client demand 看透明度和客户偏好；Regulation 看 hard/soft law 上升。

NOT / Exception

必背陷阱

  • Engagement 是唯一不属于 portfolio construction 的 responsible approach。
  • Best-in-class = positive screening；ethical / faith-based 多用 negative screening。
  • Impact investing ≠ philanthropy：impact 仍有 financial return。
  • CSR 是公司经营承诺；ESG investing 是投资者分析和组合构建。
  • Thematic / best-in-class fund 不一定天然就是 responsible investment。
